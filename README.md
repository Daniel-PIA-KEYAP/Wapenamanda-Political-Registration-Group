# Wapenamanda-Political-Registration-Group

Official Voter & Candidate Support Registration Portal

## Admin and Candidate Structure

- Each candidate will act as an admin and have access to view users only within their own category or section.
- Candidates will NOT be able to view the users in other candidates’ sections or consoles.
- All candidates are automatically created as admins upon registration.
- When a candidate registers, a unique/private console is created for them. Each candidate will have their own dedicated console to manage their users.
- Candidates will register in the “Candidates Registry” section or console.
    - Once registered, candidates are listed alphabetically.
    - Registered candidates will also appear in the “Users Registry” section or console, allowing users to select which candidate they want to be part of.
